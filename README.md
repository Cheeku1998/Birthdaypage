# ❤️ Birthday Website V3 — Slideshow + Music

## Folder structure

```text
birthday-for-her/
├── index.html
├── music.mp3
└── photos/
    ├── photo1.jpg
    ├── photo2.jpg
    ├── photo3.jpg
    ├── photo4.jpg
    ├── photo5.jpg
    └── photo6.jpg
```

## 1. Personalize

Open `index.html` and replace `[HER NAME]` and `[YOUR NAME]`.

Change:

```js
const birthdayMonth = 7;
const birthdayDay = 26;
```

## 2. Add photos

Put your photos inside `photos/` and name them:

- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg
- photo5.jpg
- photo6.jpg

## 3. Add music

Put a music file named exactly:

`music.mp3`

next to `index.html`.

Use music you have permission to use. Browsers generally block audio autoplay, so this site starts the music after the visitor clicks a button.

## 4. GitHub Pages

Upload `index.html`, `music.mp3`, and the `photos` folder to your repository root.

Then:
**Settings → Pages → Deploy from a branch → main → /(root) → Save**

No npm or build command is needed.
